# Setup guide

## Direct public playlist URLs

- Sports: `https://iptv-org.github.io/iptv/categories/sports.m3u`
- Movies: `https://iptv-org.github.io/iptv/categories/movies.m3u`
- Entertainment: `https://iptv-org.github.io/iptv/categories/entertainment.m3u`
- All channels: `https://iptv-org.github.io/iptv/index.m3u`

## VLC

1. Install VLC from https://www.videolan.org/vlc/.
2. Select **Open Network Stream**.
3. Paste a direct M3U URL above and select **Play**.
4. Open the playlist view to browse channels.

## TiviMate / IPTV players

1. Install a trusted IPTV player.
2. Select **Add playlist** > **M3U playlist**.
3. Paste a direct category URL above.
4. Save and refresh the playlist.

The local .m3u files in this repository are pointers to category playlists and may not play in clients that do not support nested playlists. Prefer the direct URLs above.

## Premium services

Use the official HBO Max, Paramount+, Starz, MGM+, MLB.TV, or participating TV-provider app with an authorized subscription. Public playlists do not unlock these services.

## Security

Avoid unknown APKs, untrusted M3U URLs, and requests for credentials or payment through unofficial sites. Free public streams may disappear or change.
