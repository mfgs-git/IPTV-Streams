# IPTV-Streams

A curated starting point for **public IPTV playlists**, premium movie-channel viewing options, and baseball streaming in the United States.

> Public M3U playlists are not subscriptions to HBO, Cinemax, Showtime, Starz, or MLB.TV. Availability, regional restrictions, and rights can change. This repository does not host or redistribute unauthorized premium feeds.

## Playlists

- [Sports](playlists/sports.m3u)
- [Movies](playlists/movies.m3u)
- [Entertainment](playlists/entertainment.m3u)

These M3U files are directory pointers, not full channel lists. Many players do not support nested playlists. For reliable playback, paste the direct category URLs from [SETUP.md](SETUP.md).
