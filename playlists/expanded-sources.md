# Expanded public IPTV sources

These are direct M3U playlist endpoints maintained by [iptv-org](https://github.com/iptv-org/iptv). They contain public stream listings, not subscriptions or guaranteed working feeds. Some streams may not play in a web browser because of CORS or format restrictions.

| Category | Direct playlist |
|---|---|
| Movies | https://iptv-org.github.io/iptv/categories/movies.m3u |
| Classic movies and TV | https://iptv-org.github.io/iptv/categories/classic.m3u |
| TV series | https://iptv-org.github.io/iptv/categories/series.m3u |
| Entertainment | https://iptv-org.github.io/iptv/categories/entertainment.m3u |
| Comedy | https://iptv-org.github.io/iptv/categories/comedy.m3u |
| Sports | https://iptv-org.github.io/iptv/categories/sports.m3u |
| United States | https://iptv-org.github.io/iptv/countries/us.m3u |
| All categories | https://iptv-org.github.io/iptv/index.category.m3u |

**Premium and PPV:** HBO, Cinemax, Showtime, Starz, and live pay-per-view events typically require subscriptions, purchases, DRM, and provider authentication. There are no verified authorized free premium feeds added here. See [premium channel options](../channels/premium-channels.md) and [M3U template](premium-and-ppv-template.m3u).

## How to use

Paste any direct URL into the web player's **Add a playlist** field, or into VLC / TiviMate. Avoid treating a URL that points to another .m3u as a video stream.
